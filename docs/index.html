🐙 Connect GitHub

Your commits are fetched using a Personal Access Token. It needs read access to your repos.

🔑 How to create a GitHub Personal Access Token?
  1. Go to github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Set a name: Daily Digest Bot
  4. Set expiration: 1 year
  5. Select scope: ✅ repo (full control of private repos)
  6. Click "Generate token" at the bottom
  7. Copy the token (starts with ghp_ or github_pat_) and paste below

⚠️ Copy the token immediately — GitHub only shows it once.
